栈外手记出品，支持简体中文 / English、深色 / 浅色主题，提供 12 个真实可用的本地开发工具。

## 在顶箭启动

在「我的发布」打开此项目，顶箭读取 `manifest.json` 并启动 `server/main.mjs`。生产资源已构建到 `public/`，运行时无需安装依赖、登录、数据库或付费 API。

端口来自 `TOPARROW_APP_PORT`，只监听 `127.0.0.1`，健康检查 `/__health`。核心计算在浏览器 Worker 进行，不上传用户输入。服务运行时断网后仍可刷新使用；关闭顶箭服务后不能继续访问页面。

开发机数据在平台注入的 `TOPARROW_DATA_DIR`，当前为项目 `data/`；应用不依赖此绝对路径。本版本不读写业务文件。`data/` 不提交、不打包。

## 已实现

- JSON：严格校验、格式化、压缩、树形浏览、缩进、保留大整数和高精度小数。
- SQL：MySQL / PostgreSQL / SQLite / 通用 SQL，格式化、词法安全压缩、关键字大小写、缩进与语法高亮；不执行 SQL、不声称完整校验。
- 时间戳：秒与毫秒、IANA 时区、UTC / 本机日期、双向转换；日期字符串与分段行均固定分隔符、只需输入数字，无日历弹窗，双向转换三行同屏，每行独立单位与结果；当前 Unix 时间戳支持开始、停止、刷新。
- Base64：UTF-8 中文及 Emoji、Base64URL、严格校验和交换。
- URL：URI 组件与完整 URI 编解码，保留重复参数、空值、等号与加号规则的 Query 编辑。
- JWT：Header、Payload、签名段、exp / iat / nbf，仅本地解析，固定显示未验证签名，大数值保真展示。
- 正则：JavaScript Flags、匹配高亮、命名及普通分组、位置、实时模式、替换预览与可终止超时。
- Diff：行级 / 字符级差异，并排和行内视图，忽略行首尾空白、统计和统一差异补丁。
- Hash：SHA-256 / 384 / 512 文本及文件摘要，不是加密。
- UUID：安全随机 v4、批量 1–1000 项、校验与大小写无关去重统计。
- Cron：标准五字段、常用模板、指定时区和十次未来执行预览；不支持 Quartz、秒字段及 L/W/#/?/H。
- 进制：二、八、十、十六进制 BigInt 整数转换，数学负数，不使用补码。

全局：工具搜索、收藏、最近使用、结果手动联动、双语、主题、字号、复制/粘贴/下载、示例、清空、错误提示和全屏查看；JSON 输入与结果一起并排全屏，支持全屏内继续处理；拖动中间分隔条调整左右宽度，双击或 Enter 恢复均分，方向键微调。传递后保留源内容，目标等待用户主动操作，已有目标输入会确认覆盖。

快捷键：Cmd/Ctrl + K 搜索，Cmd/Ctrl + Enter 执行，Esc 关闭弹窗或应用内全屏。

## 示例与预期

- JSON：`{"name":"中文","n":9007199254740993}`，格式化保留数值，再压缩得到单行语义等价结果。
- Base64：`中文` ↔ `5Lit5paH`。
- 时间戳：`1735689600` 秒 / 上海 → `2025-01-01 08:00:00`，UTC → `2025-01-01T00:00:00.000Z`，毫秒 → `1735689600000`。
- Query：`?a=1&a=2&empty=&v=a%3Db&space=a+b`，保留两个 a，空 empty，v 为 a=b，space 为 a b。
- SQL：`select id from users where name='中文 user'`，关键字大写后字面量保持不变。
- JWT：使用工具内演示令牌，Payload sub 为 example，exp 为 `2025-01-02T00:00:00.000Z`，始终未验证签名。
- 正则：`#(?<id>\d+)`、Flags g、`Order #1024 · 订单 #2048` → 2 个匹配，替换 `ID:$1` → `Order ID:1024 · 订单 ID:2048`。
- Diff：工具内两段示例显示 2 行修改和对应字符差异。
- Hash：abc 的 SHA-256 为 `ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad`。
- UUID：生成 5 项得到 5 个随机合法 v4；示例两条大小写不同 UUID 检出 1 个重复项。
- Cron：`0 9 * * 1-5` / Asia/Shanghai，在 `2025-01-01T00:00:00Z` 后第一次为 `2025-01-01T01:00:00.000Z`。
- 进制：十进制 `9007199254740993` → 十六进制 `20000000000001`；十六进制 `-ff` → 十进制 `-255`。

## 开发与生产构建

使用顶箭自带 Node（建议 24，最低 22）和 npm 8+。将顶箭 Node 所在目录加入当前终端会话 PATH；Mac 默认位置为 `/Applications/TopArrow.app/Contents/Resources/runtime/node/bin`，以实际安装位置或 `TOPARROW_RUNTIME_DIR` 为准，不能将开发机路径写进运行时代码。

```sh
npm ci
npm run dev
npm test
npm run build
npm run release:prepare
```

开发依赖安装需要网络，运行应用不需要网络。`npm run dev` 为开发预览；顶箭打开使用 `public/`，改源码后必须构建再刷新。

`release:prepare` 构建后生成图标、生产依赖许可和干净 ZIP。市场使用 `release/DevKit-market-ready.zip`，不要上传整个源码工作区。包内没有 Git、node_modules、用户数据、开发说明或运行时。工具处理逻辑已编译到本地静态资源。

SQL 固定 sql-formatter 15.9.0，压缩复用其词法器；升级此库必须回归字符串、注释及方言测试。Monaco 按需加载，资源较大，会产生构建体积提示；编辑器部分内置菜单和诊断为英文。

## 隐私与限制

输入与结果只在本次页面会话内保留，刷新清除，不自动记录输入历史。localStorage 仅保存语言、主题、字号、缩进、收藏和最近工具 ID。清空本地数据会同时清除输入、结果和文件选择并取消任务。其他设备或扩展环境仍可能影响隐私，不能保证绝对安全。

- 文本 2 MiB；文件摘要 32 MiB；正则 1.5 秒，其他转换 8 秒超时。
- 正则 2,000 个匹配、255 个捕获分组，替换展开量有资源上限。位置使用 UTF-16 索引。
- JSON 树最多 3,000 行；Query 编辑最多 1,000 项。
- Diff 最多 10,000 行，界面显示前 1,500 行；完整补丁可复制或下载。忽略空白指行首尾空白。
- 进制整数最多 10,000 位，不接受小数和前缀。
- 无偏移日期按所选时区解释；夏令时缺失/重复时刻明确报错，粘贴带偏移 ISO 可指定明确时刻。
- 剪贴板、文件选择和下载可能受宿主权限限制；失败时提示，不自动提升权限。
