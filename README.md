## About this version

This update improves workspace layouts, text comparison, and date input.

- **Expanded workspaces**: View inputs and results together within the app for SQL, Text Diff, and other tools.
- **Resizable columns**: Drag the center divider to adjust panel widths. Double-click to restore equal widths.
- **Adjustable heights**: In the expanded Text Diff workspace, drag the horizontal divider to resize the source and comparison areas.
- **Clearer differences**: Stronger highlighting makes additions, deletions, and changes easier to identify.
- **Automatic date completion**: Missing month and day fields default to 01; missing time fields default to 00. Date input B starts with the current year.
- **Ready-to-use timestamps**: The current Unix timestamp is filled in when opening or clearing the timestamp tool.
- **Improved navigation**: Larger icons and click areas fix the compressed icons in collapsed navigation.

Local processing, Chinese and English support, and light and dark themes remain available.
