## About this version

This update expands DevKit to 22 tool entries and improves navigation, file processing, and live previews.

- **All Tools page**: Browse a categorized grid with search, favorites, and vertical scrolling.
- **Image compression and cropping**: Batch-process images, resize, crop by dragging, export JPEG/PNG/WebP, and download a ZIP. Auto mode preserves the source format and can retain the smaller original when dimensions are unchanged.
- **PDF to Word**: Extract text PDFs into editable Word documents with page breaks. Scanned PDFs, OCR, complex tables, images, and original layout reconstruction are not supported.
- **Live QR previews**: Content, titles, font sizes, and positions update automatically. Place titles above, below, or in a limited center overlay, and include them in PNG exports.
- **More everyday tools**: Text utilities, Unicode, HTML entities, JSON/CSV/YAML conversion, colors, secure passwords, and Markdown preview.
- **Flexible workspaces**: Expand multi-panel tools within the app and resize columns. Text Diff also supports adjustable source and result heights.
- **Interaction fixes**: Improved Markdown spacing, localized file buttons, numeric editing, and preview controls without flickering cancel buttons.

Processing remains local. Inputs and files are not uploaded. Chinese and English interfaces and light and dark themes are supported.
