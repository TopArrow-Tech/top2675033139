# 2026-11-03 DevKit Phase 1

## 目的
按用户需求建设第一阶段真实可用的开发者工具；确认中英双语，选择本地 Monaco 编辑器。本轮不涉及发布。

## 实现
- React/TypeScript/Vite 项目、品牌、深浅主题、中文/English、折叠导航与搜索。
- JSON 保留大整数与高精度小数，严格校验，支持格式化、压缩、树形展示和缩进。
- Base64 UTF-8、URL-safe、非法填充/非法字节校验。
- 时间戳显式单位和时区，通过 Temporal 处理日期和夏令时。
- URL 编解码与有序 Query 参数编辑，保留重复名、空值与等号。
- Worker 按需算法加载、2 MiB 输入限制、8 秒终止超时、旧任务取消和结果隔离。
- Monaco 仅引入当前编辑能力，本地加载编辑器与 JSON Worker，不走 CDN。
- 本地偏好设置、剪贴板/下载、空输入和存储/加载异常提示；输入不落盘。
- Node 标准库静态服务、环境端口、回环监听、健康检查、安全响应头。

## 文件
核心源码 src/；启动 server/main.mjs；生产产物 public/；manifest、package 与构建配置；README、第三方许可、项目结构与测试说明。data/ 加入忽略，不修改 AGENTS.md。

## 验证与限制
核心测试和生产构建；Mac 生产页面检查。Windows 实机、其他顶箭宿主权限差异以及应用市场发布自检待后续执行。Monaco 本身部分菜单/诊断为英文。大 JSON 树限制 3,000 行，Query 编辑限制 1,000 项。

## 第二至四轮扩展

- src/app/registry.ts 集中工具分类、搜索关键词和示例；收藏与最近使用只保存 ID。
- 工作台统一手动传递接口；目标已有输入时确认覆盖；保留源内容，不自动执行。
- src/workers/advanced.worker.ts 按需载入算法，正则 1.5 秒，其余 8 秒超时，支持取消和切换终止。
- 固定数字日期输入 DateInput.tsx，无日历；方向、秒/毫秒改为分段按钮。
- 结构化结果按工具保存；错误边界隔离；全局清空同步销毁结果、文件引用与任务；12 工具侧栏内部滚动。
- SQL 锁定 sql-formatter 15.9.0，复用其词法器安全压缩；JWT 保真展示大数值；Diff 显示末尾换行差异；正则捕获、匹配和替换资源限制；Monaco 图标字体本地化。
- scripts/prepare-release.mjs 生成原创 PNG/SVG 图标、汇总生产依赖许可并生成无 .git/用户数据/开发依赖的 ZIP。
- 市场介绍、隐私说明、发布自检和验收记录位于 _doc/输出文案 与 _doc/testcase/full-suite.md。
- 97 项自动测试通过；Mac 生产页面多工具及联动验证通过。顶箭本机界面连接超时；Windows 与平台内实机确认列为待验收，不宣称已通过或已发布。

## 紧凑布局与同屏对照
- 用户反馈顶部留白与窄编辑区影响大数据查看：标题和工具联动合并一行，收紧顶部、导航、操作栏，保持编辑器字号。
- 时间戳从双栏卡片切换为参考图式三行表单，双向转换同时可用，顶部提供当前 Unix 时间戳开始/停止/刷新；各行单位、结果、复制与错误独立，详细时区信息折叠展开。
- 新增 timestamp/Workbench.tsx，复用 process.worker.ts 和严格算法；输入与结果仍只在内存，不自动执行。input.ts 提供斜杠日期标准化及相应边界测试。
- JSON 全屏改为输入/结果双栏共同展开，同一编辑器实例保留，提供全屏内转换、错误和退出操作；恢复焦点并隔离背景控件。
- 98 项核心测试、类型检查与生产构建通过；页面验证三行转换、单位切换、非法日期、停止时钟、JSON 双栏全屏与压缩。更新分发资源和界面截图。

## 统一按钮与可拖动分栏
- 时间戳三行采用统一网格区域，转换、单位、结果和复制保持同列，窄容器自动换成一致的两行布局；提供不支持容器查询时的媒体查询后备。
- 新增 timestamp/MaskedDateInput.tsx 与 mask.ts：日期字符串先显示固定分隔符，数字自动跳过符号，删除不移位，支持粘贴标准日期、14 位数字及带偏移 ISO，仍由原算法严格校验。
- 新增 editor/SplitDivider.tsx 与 split.ts：Pointer Capture + 动画帧合并拖动，左右 20%–80% 边界、双击恢复 50/50、方向键微调，Monaco 保持挂载且自动调整。
- 108 项测试、类型检查与生产构建通过。1280px 页面实测按钮列一致，980px 内嵌视口实测换行仍对齐；真实鼠标拖动、均分恢复、键盘调整和数字日期转换均通过页面验证。
- 更新架构、使用说明、分发包及相关截图；临时布局探针已删除。

## 日期字符串外观统一
- 按用户参考，去掉日期字符串的下划线占位，复用 DateInput 的 YYYY - MM - DD HH : mm : ss 六段外观。MaskedDateInput 保留行适配接口，DateInput 增加可选分组标签、回车执行及 14 位数字粘贴。
- 数字自动跳字段、标准日期/ISO 粘贴和时区处理继续保留，不引入日历弹窗。
- 108 项测试、类型检查与生产构建通过；页面验证连续数字输入和整段数字粘贴后均正确转换，保存空白占位参考截图并同步分发包。
