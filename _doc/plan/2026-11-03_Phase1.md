# DevKit Phase 1 实施方案

## 背景与目标
开发者品牌「栈外手记」；应用显示名称「开发者效率工具箱」，产品名 DevKit。用户确认中英双语，授权选择合适编辑器，先完成需求书 Phase 1。后续在顶箭应用市场发布，本轮不发布。

## 技术方案
- React 18、TypeScript、Vite；本地 Monaco 编辑器按需加载，只引入 JSON 和本阶段使用的编辑能力。
- 顶箭 Node 运行时提供静态资源与健康检查，无业务后端和数据库。所有数据计算在浏览器 Worker 执行。
- Node 仅监听 127.0.0.1，端口来自 TOPARROW_APP_PORT。不在运行时代码中写死开发机路径。
- JSON 使用原生解析器严格校验语法，再用 json-bigint/BigNumber 保留数值精度；Base64 使用 UTF-8 严格解码；时间使用 Temporal polyfill，拒绝无明确偏移的夏令时歧义；URL 使用标准 URI API 与有序 Query 列表。
- 翻译集中在 src/locales；localStorage 只保存主题、语言、缩进和字号，不保存工具输入。
- 工具输入上限 2 MiB；Worker 8 秒超时终止。树形视图限制行数以控制 DOM 数量。

## 涉及文件
src/app 工作台；src/components 编辑器；src/tools 各工具独立逻辑；src/workers 可中断计算；src/locales 双语；src/tests 验证；server/main.mjs 顶箭启动；public 生产资源。

## 注意事项
- 仅实现 JSON、Base64、时间戳、URL，后续工具不以占位按钮冒充完成。
- public 构建结果必须随应用打包；运行时无需 node_modules。
- 开发机 data/ 不参与提交；将来实际业务文件只写 TOPARROW_DATA_DIR。本期不读写业务文件。
- Windows 和 Mac 使用同一源码；本机验证不等于已完成 Windows 实机验收。
