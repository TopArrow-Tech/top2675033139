# DevKit 第二至四轮实施方案

用户授权继续第 2、3、4 轮，完成全部工具、联动、测试和上架素材准备，不提交市场发布。

- 保留已有四工具，新增独立模块工作台和可终止 Worker：SQL、JWT、正则、Diff、Hash、UUID、Cron、进制转换。
- SQL 使用 sql-formatter；压缩必须使用词法 token 信息保护字符串与注释，不实现伪校验。
- JWT 仅解析，固定显示未验证签名，不持久化输入。
- JavaScript 正则使用独立线程、短超时、匹配数量限制、零长度推进；React 安全渲染高亮和分组。
- Diff 使用成熟 diff 包，行级并排/行内与字符级高亮，保留原始文本。
- Hash 使用 Web Crypto；UUID 使用安全随机数；Cron 明确标准五字段及 IANA 时区；进制使用 BigInt。
- 工具注册表统一搜索、分类、收藏、最近使用。统一手动传递接口，原内容保留，目标等待主动操作。
- 扩展中英语言文件，设置仅保存偏好和工具 ID，不保存输入。
- 完成算法测试、生产构建、页面验证；生成原创代码图形图标、市场介绍、截图和干净分发包，保留许可。
- 发布检查以最终分发目录为准，排除 .git、node_modules、data、开发说明文件。Windows 实机、顶箭内打开与平台审核不能由浏览器预览代替。
