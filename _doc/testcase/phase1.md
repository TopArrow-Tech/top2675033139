# Phase 1 验证

自动测试：`npm test`。覆盖 JSON 原始值、严格语法、大整数/小数、特殊键名，Base64 Unicode/URL-safe/非法填充/UTF-8，URL 保留字符/重复参数/百分号错误，时间单位/偏移/时区/夏令时/非法日期和输入上限。语言键集合一致。

构建：`npm run build`（TypeScript + Vite）。

生产页面检查：
1. 顶箭「打开」，或以平台环境启动 server/main.mjs，访问根页面和 /__health。
2. JSON 示例格式化、压缩、树形折叠；非法输入显示错误；数值 9007199254740993 不变化。
3. Base64 示例编码 → 交换 → 解码，恢复中文及 Emoji；清空后两侧均为空。
4. URL 示例解析保留两个 q、空 empty 和值 a=b；编辑参数并重新生成。
5. 时间戳示例秒 → 上海 2025-01-01 08:00:00 / UTC 00:00:00；切换日期方向验证反向转换。
6. 中英切换、浅色主题、字号、刷新后偏好保留；刷新前的输入不保留。
7. Cmd/Ctrl+K 搜索中文/英文、Enter 进入工具；Cmd/Ctrl+Enter 执行；Esc 关闭弹窗。
8. 复制、粘贴、下载（宿主拒绝时有错误提示）；复制 JSON 文件中数值不丢精度。
9. 大输入运行中切换工具/修改输入，旧结果不得覆盖；超限、超时明确报错。
10. Windows 与 Mac，1366×768、1440×900、1920×1080 分别检查无关键控件遮挡。

本机测试不能替代 Windows 和不同顶箭宿主的实机验收。发布前按 publish_check.md 另行执行完整自检。
