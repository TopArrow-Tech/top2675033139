# 1.1.0 版本发布文案

中文版本名：图片处理与文档转换
英文版本名：Images, Documents & Text Tools

## 中文版本介绍

新增 10 个工具入口，工具箱扩展至 22 项，可在默认“全部工具”网格页按分类、搜索和收藏浏览：

- 图片压缩与裁剪：本机批量压缩、调整尺寸、JPEG/PNG/WebP 输出、拖动裁剪和打包下载；默认保留原格式，未变小时可返回较小原图。
- PDF 转 Word：文字型 PDF 提取为可编辑 Word，保留页分隔；扫描件暂不支持 OCR，复杂表格、图片及原始排版不保留。
- 文本整理：按行去重、排序、清理空白、命名风格转换和统计。
- Unicode 与 HTML 实体转换。
- JSON、CSV、YAML 格式转换。
- HEX、RGB、HSL 颜色转换与黑白对比度。
- 安全随机密码生成：可选长度、数量及字符集。
- 二维码生成与 PNG 下载，支持标题、字号、上下位置和对齐。
- Markdown 本地预览与静态 HTML 导出。

保留原有 12 个开发工具、双语、主题、搜索、收藏与工具联动。新增文本工具支持双栏全屏和拖动分栏。所有处理在本机完成，不上传工具输入或文件。

## English release notes

Adds 10 tool entries, bringing the toolkit to 22, with a searchable, categorized All Tools grid:

- Images: batch compression, resizing, JPEG/PNG/WebP export, drag-to-crop, and ZIP download with before/after sizes.
- PDF to Word: extracts text PDFs into editable paragraphs with page breaks. OCR, images, complex tables, and original layout reconstruction are not supported.
- Text utilities: deduplicate and sort lines, trim whitespace, change naming styles, and count text.
- Unicode and HTML entity conversion.
- JSON, CSV, and YAML conversion.
- HEX, RGB, and HSL colors with black/white contrast ratios.
- Secure local password generation with configurable character sets.
- QR generation and PNG download with title, font size, position, and alignment controls.
- Markdown preview and static HTML export.

Retains the original 12 tools, bilingual interface, themes, search, favorites, and manual tool transfer. New text workspaces support expanded views and resizable columns. Processing stays local; inputs and files are not uploaded.
