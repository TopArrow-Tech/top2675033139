# 应用市场发布文案

应用名称：开发者效率工具箱
英文名称：DevKit
开发者：栈外手记
建议分类：开发工具 / 效率工具

## 一句话简介
集成 12 款本地开发工具，支持 JSON、SQL、编码转换、正则、文本对比与时间计算，中英切换，打开即用。

## 完整介绍
DevKit 是一款面向程序员、测试工程师和运维人员的本地开发工作台。无需注册、数据库或付费 API，将常用的数据处理工具集中在同一个界面中。

**12 个实用工具**
- JSON：格式化、压缩、严格校验、树形浏览，保留大整数精度。
- SQL：MySQL、PostgreSQL、SQLite、通用 SQL 格式化，关键字大小写、缩进和安全压缩。
- 时间戳：明确区分秒与毫秒，支持指定时区、UTC 与本机时间，双向转换三行同屏；固定分隔符输入，不用手动输入横线和冒号。
- Base64：支持 UTF-8 中文、Emoji 与 Base64URL。
- URL：组件与完整 URI 编解码，Query 参数解析、编辑和重新生成，保留重复参数与空值。
- JWT：本地查看 Header、Payload、签名段及时间声明；仅解析，不验证签名。
- 正则：JavaScript 正则匹配、高亮、捕获分组、位置和替换预览，复杂匹配支持超时终止。
- 文本对比：并排与行内视图、行级和字符级差异、统计和统一差异补丁。
- Hash：SHA-256、SHA-384、SHA-512 文本与文件摘要。
- UUID：安全随机 UUID v4、批量生成、格式检查和去重统计。
- Cron：标准五字段表达式、常用模板、时区与未来十次执行预览。
- 进制转换：二、八、十、十六进制整数转换，支持大整数和数学负数。

**为日常工作准备**
支持深色与浅色主题、中英双语、工具搜索、收藏和最近使用。JSON 输入与结果可在应用内并排全屏对照、编辑和查看，工具结果可手动发送到其他工具，源内容保留，目标等待主动执行。

**本地优先**
核心处理无需联网，不上传输入，不接入统计或追踪服务。输入仅在当前页面会话中保留，刷新清除；浏览器只保存主题、语言、编辑器偏好和工具标识。剪贴板仅在点击复制或粘贴时访问，文件仅在用户选择并执行摘要时在本机读取，不对局域网开放。

**使用边界**
本应用不执行 SQL，不验证 JWT 签名，也不将 SHA 摘要当作加密。Cron 是标准五字段格式，不是 Quartz。单次文本上限 2 MiB，文件摘要上限 32 MiB；正则最长约 1.5 秒，其他转换最长约 8 秒，超限会提示。JSON 树最多 3,000 行；Query 编辑最多 1,000 项；Diff 处理最多 10,000 行，界面显示前 1,500 行，完整差异可复制或下载。设备及浏览器环境仍会影响隐私与使用体验。

## 本次版本说明
首次提供完整 12 工具工作台、双语和主题设置、工具收藏与联动；日期采用固定分隔符数字输入，支持 JSON 应用内全屏；补充算法校验、异常提示与处理超时保护。

## 隐私说明
不需要账号，不收集或上传工具输入，不使用广告或行为分析服务。偏好设置保存在本机浏览器，设置中可清空应用本地数据。JWT 等输入不会自动持久化。卸载、浏览器数据清理或宿主环境变化可能使偏好丢失。
